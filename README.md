# Happy Friendship Day - Cute Tap-To-Open Web App 💖✨

A trending, interactive **Tap to Open Friendship Day** website styled in **Claymorphism** (soft 3D clay effect, rounded pill shapes, inner/outer shadows, and rich pastel gradients).

## 🌟 Features
- **Claymorphism Aesthetics**: Soft 3D tactile card layouts with pastel color palette (*Bubblegum Pink*, *Mint Green*, *Lavender*, *Golden Sun*).
- **Interactive Yes/No Progressive Angry Gatekeeper**:
  - **Stage 0**: Initial Question ("Do you want to open your gift?").
  - **No Click 1**: Shocked 3D Clay Cartoon + *"HOW DARE YOU?!"* with back option.
  - **No Click 2**: Super angry temper tantrum cartoon + *"ARE YOU SERIOUS RN?!"*.
  - **No Click 3**: Crying in corner cartoon + dodging/running away `No` button and pulsing mega `YES` button.
  - **When Yes Selected**: Happy dancing character + *"YAYYY! I KNEW IT!"* + **Open Your Gift 🎁** button.
- **Multi-Slide Secret Message Journey**: 3 secret cards with cute cartoon figures leading to a grand Happy Friendship Day finale with confetti celebration!
- **Sound Effects & Audio Engine**: Web Audio API background music engine & synthesized cute pop chimes.
- **Floating Canvas Particles**: Floating hearts and stars canvas animation.

## 🚀 How to Run Locally
1. Clone or download this repository.
2. Open `index.html` directly in any web browser, or serve using any static server (e.g. `npx http-server` or `python -m http.server 3000`).

## 🛠️ Built With
- HTML5
- CSS3 (Claymorphism Design System)
- Vanilla JavaScript (Web Audio API & HTML5 Canvas)
- Canvas Confetti Library
